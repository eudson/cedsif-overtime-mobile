# Horas Extras

Flutter application for managing overtime at CEDSIF.

## Getting started

Run `make setup` once, then use `make run-dev` for development. Before
committing changes, run `make ci-check`.

Values supplied through `--dart-define` or `--dart-define-from-file` are
embedded in the built application. Keep real secrets out of the tracked
environment files; they contain placeholders only.
